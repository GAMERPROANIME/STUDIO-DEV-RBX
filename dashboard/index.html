Installation

    
    
      
  1. Ouvrez chrome://extensions (ou about:debugging pour Firefox) et activez le mode développeur.
    2. 
      
  2. « Charger l'extension non empaquetée » → dossier extension/.
    3. 
      
  3. Ouvrez le popup, collez le token, choisissez un mode, cliquez « Connecter ».
    4. 
      
  4. En mode manuel, cliquez « Autoriser 10 min » avant chaque session.
    5. 
      
  5. Optionnel : python -m omnibridge.bridge.install --extension-id <id> pour le Desktop Bridge.
    6. 
    

    
Modes

    
manual     : l'utilisateur autorise une fenêtre de 10 min
contextual : contexte de l'onglet actif (texte, sélection, liens, capture)
developer  : mode contextual + métadonnées techniques (meta, scripts, timings)
research   : lecture seule — capture et infos techniques refusées
